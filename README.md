# SmartTable-PNJVS
## Opis projekta
SmartTable je web aplikacija za upravljanje rezervacijama stolova u restoranu
## Tehnologije
-Java
-Spring Boot
-Thymeleaf
-MySQL
## Funkcionalnosti
### Korisnik
-Datum
-Vrijeme
-Broj osoba
-Kreiranje rezervacije
### Administrator
-Dodavanje stolu
-Uređivanje stolova
-Brisanje stolova
-Pregled svih rezervacija
### Status projekta
Projekt je trenutno u fazi planiranja.
