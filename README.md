# SmartReservation-PNJVS
## Opis projekta
SmartReservation je web aplikacija za upravljanje rezervacijama stolova u restoranu
## Tehnologije
-Java
-Spring Boot
-Thymeleaf
-MySQL
## Funkcionalnosti
### Korisnik
-Unos imena i prezimena
-Unos broja mobitela
-Odabir datuma rezervacije
-Odabir vremena rezervacije
-Odabir broja osoba
-Odabir stola
-Kreiranje rezervacije
### Administrator
-Pregled svih rezervacija
-Uređivanje rezervacija
-Brisanje rezervacija
-Dodavanje stolova
-Uređivanje stolova
-Brisanje stolova
### Status projekta
Projekt je trenutno u fazi planiranja.
